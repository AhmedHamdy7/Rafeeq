## ✅ Backend done: TRIPS-14 Status filters on `/seat-requests` and `/seat-offers` (B-14)

**Merged to `main`** in `d4481b0`. Guide §4.7 updated on both endpoints.

### How to call
| Tab | Call |
|---|---|
| Requests | `GET /seat-requests?status=PENDING,COUNTEROFFERED` |
| Waiting list | `GET /seat-requests?status=WAITLISTED` |
| Offers (open) | `GET /seat-offers?status=OPEN` |
| Offers (history) | `GET /seat-offers?status=ACCEPTED,DECLINED,TAKEN_BY_OTHER,CLOSED,INELIGIBLE,WITHDRAWN` |

- A comma-separated list, any case. Paging (`page`, `perPage`) and `meta.hasMore` apply to the **filtered** list.
- An unknown status → `422 VALIDATION_FAILED` (`error.fields.status`).
- Without `status`: every row, as before. Nothing breaks for the current app.
- `/seat-offers` now honours `perPage` too (it used Laravel's default 15 before).
