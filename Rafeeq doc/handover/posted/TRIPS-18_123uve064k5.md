## ✅ Backend done: TRIPS-18 Passenger cancel-fee preview on a booking (B-18)

**Merged to `main`** (see the commit "Passenger cancel-fee preview on a booking (TRIPS-18)"). New endpoint, so the guide now counts 188. Guide §4.7 → `GET /bookings/{booking}/cancel-preview`.

### The call
`GET /bookings/{booking}/cancel-preview` (her own booking only; the driver gets `404`)

```json
{ "feePiastres": 1425, "reason": "late_cancel_fee", "warning": true, "rung": 2, "waivedIfRefilled": true }
```

| Field | Means |
|---|---|
| `feePiastres` | The exact amount, or `0` |
| `reason` | `none` (more than 12 h ahead: free) · `late_cancel_warning` (counts on her late-cancel counter, no money this time) · `late_cancel_fee` (money) |
| `warning` | `true` when it counts on the late-cancel counter |
| `rung` | Her step on that counter (1 = first), `null` outside the window |
| `waivedIfRefilled` | The fee is dropped if a waiting passenger takes the seat before departure (R-8) |

It's computed by the same rule `PATCH /bookings/{booking}/cancel` runs, so the preview and the charge agree (tested).
